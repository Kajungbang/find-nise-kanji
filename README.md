# 間違い文字チェッカー（Find Nise-Kanji）

AIが書いた日本語に紛れ込む簡体字・旧字体・ハングル・キリル文字などの**間違い文字**を、コピペ1本で見つけるツールです。

- 「**報**告」のはずが「**报**告」——ChatGPTやClaudeに日本語を書かせると、たまに簡体字が混ざります
- フォントによっては目で見てもほぼ区別がつきません
- このツールは**Pythonの標準機能だけ**で動きます。追加インストール不要です

## 使い方

```bash
python3 mistake_kanji_check.py 調べたいファイル.txt
```

同梱の `sample.txt` で試すと：

```
1行目: 「报」 ← この行にあります: 今日の报告をまとめました。
3行目: 「时」 ← この行にあります: データの时系列を确認しました。
3行目: 「确」 ← この行にあります: データの时系列を确認しました。
```

間違い文字（报・时・确）だけが検出され、正しいけれど珍しい「憂鬱」「卓越」には誤検出しません。

## 仕組み

「珍しい字を疑う」のではなく、**日本語の漢字の公式名簿（JIS規格）に載っているか**を1文字ずつ照合します。

1. **名簿照合**：JIS系エンコーディング（shift_jis_2004 等）への変換可否で判定。載っていない字＝間違い文字。**ハングルの混入も同じ照合で検出します**（ハングルはJIS名簿に一切載っていないため）
2. **要注意リスト（SIMP）**：名簿に載って*しまっている*要注意の字137字を別途照合
   - 中国語系105字：Unicode公式の[Unihanデータベース](https://www.unicode.org/Public/UCD/latest/ucd/)の簡体字属性とJIS名簿を突き合わせて機械生成（98字）＋手動補完（7字）
   - 旧字体15字：AIが現代文で書いたらほぼ誤りの字（收・對・增 など）。**人名・古典の引用を含む文章を調べる場合は、スクリプト内の該当1行を削除してください**（假屋崎さん・續木さんなど実在の人名では正しい字のため）
   - 採集17字：実際のAI出力の誤記記録との月次照合で見つけた、リスト外の間違い文字（偙・裌・斅 など）。「冲」のみ人名（冲方さんなど）では正しい字のため、該当する場合はスクリプト内の該当1行から除いてください
3. **キリル文字**：意外にもJIS名簿に収録されているため名簿照合では捕れず、**範囲ごと問答無用で検出**します（операции→操作 のような翻訳等価語の置換が実際に起こるため）。ロシア語の原文引用を含む文章ではスクリプト内の判定を外してください。なおギリシャ文字（α・β等）は日本語で正当に使われるため検出しません

リストの再生成は `tools/build_simp_list.py` で誰でも再現できます。

## 限界（重要）

- **「見つからなかった」＝「ゼロ」ではありません。** このツールが捕れるのは「名簿にない字」と「要注意リストの字」だけです。正しい日本語漢字への化け（「時」→「侍」等）は原理的に検出できません
- 作者の運用記録（AIの誤字349字種）との照合では、126字種（約36%）を機械検出できました。残りの約64%は「正しい日本語漢字への化け」で、名簿方式では捕りきれない領域です
- 検出した字をAIに一括修正させるのは非推奨です。簡体字→日本語のように答えが1つのものは安全ですが、数値・固有名詞は元資料との照合を推奨します
